# Creator go-live onboarding guide

Design brief for first-time creators: the shortest path from signup to taking bookings or shop orders.

**Audience:** new creator (second person — “you”), not staff.

**Goal:** get cover, profile, payouts, and either shop or bookings ready so they can go live.

---

## Flow overview

```
Cover → Bio → Payments → Pick path (Shop and/or Bookings) → Live
```

Shared setup first, then product-specific steps.

---

## Shared steps (everyone)

### 1. Update cover image
- **Where:** Dashboard / business card cover
- **Why:** First thing clients see on the public page
- **Done when:** A cover/banner is uploaded

### 2. Update bio (Settings)
- **Where:** Settings → Profile
- **Why:** Name, bio, and basics so the page feels real
- **Done when:** Bio (and core profile fields) saved

### 3. Set up payment account (Earnings)
- **Where:** Earnings → bank / payout setup
- **Why:** Required to settle money after bookings or sales
- **Done when:** Nigerian bank account linked and ready for settlement

---

## Path A — Shop (if they sell)

### 4a. Set up shop
- **Where:** Shop
- **Tasks:**
  - Add products (and preorders if relevant)
  - Configure **orders** handling
  - Configure **delivery** if it applies
- **Done when:** At least one product is listable and order/delivery preferences are set (skip delivery if digital-only / pickup-only as product rules allow)

---

## Path B — Bookings (if they take sessions)

### 4b. Set up bookings
- **Where:** Bookings
- **Tasks (in order):**
  1. **Availability** — when clients can book
  2. **Services / bookings** — what they offer and prices
- **Done when:** Availability is set and at least one bookable service exists

---

## End state

### You’re live
- Public page shows cover + bio
- Payouts linked
- Shop products and/or bookable services are discoverable
- Clients can pay; creator share settles to the linked bank via Paystack (next business day on Paystack’s cycle — no separate “withdraw” step)

---

## Suggested UI patterns (for design)

- **Checklist card or drawer** on dashboard, progress 1 → N
- Deep links per step (cover / settings profile / earnings / shop / bookings availability / bookings services)
- Mark complete by action or “I’ve done this”
- Optional: hide shop steps if they only chose bookings (and vice versa), based on onboarding use cases
- Final celebratory “You’re live” state with link to public page

---

## Copy tone

- Talk **to the creator**: “Add your cover”, “Link your bank”, “Set when you’re available”
- Avoid internal/product jargon when a plain action works (“Go live” not “complete onboarding flags”)
- Settlement: explain briefly that paid bookings/shop sales settle to their linked Nigerian bank — no withdraw request

---

- [ ] Shop branch: products + orders + delivery (if applicable)
